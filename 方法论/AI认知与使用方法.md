# AI认知与使用方法（核心方法论）

> 变更记录：2026-08-22 重大认知更新。
> 背景：凌晨与用户深度讨论AI运作方式，发现QClaw知识判断失灵的根因，整理为方法论。

---

## 一、AI运作方式的底层逻辑

### 上下文窗口限制
AI不是"知道所有知识"，而是在**当前上下文窗口里运行**，只调用上下文中出现过的知识。

具体表现：
- 聊后端 → 只调后端知识
- 聊前端 → 只调前端知识
- 没聊过 → 默认"不存在"
- 节省消耗 → 自动过滤不相关知识

### MEMORY系统的本质
MEMORY.md 是**外部记忆**，用来对抗上下文窗口的限制。

如果 MEMORY 里没写"MEMORY里没写" → AI 不知道要调用
如果 MEMORY 里只写了后端路线 → AI 默认只走后端
如果 MEMORY 里没有创业视角 → AI 用打工者视角判断

**MEMORY 是让AI在当前上下文之外还能"记住"关键信息的工具。**

## 二、QClaw的知识判断失灵案例（2026-08-22）

### 事件：拒收SR.D和Motion Sites
- QClaw 判断：设计展示/网站灵感，"非技术必需"，拒收
- 真实原因：用工程师标准判断设计资源——能写代码才有用，不能就拒
- 结果：最直接回答"怎么做才好看"的资源被排除

### 根因
1. **上下文窗口限制**：讨论全程都是后端，QClaw没有调用前端知识
2. **工程师视角**：只看到"代码组件"，看不到"设计灵感"的价值
3. **MEMORY缺失**：MEMORY里没有"创业视角：审美是竞争力"，只有"Python后端路线"

### 教训
AI不是"不知道"，是"不在上下文里就不调用"。
MEMORY里没写的，AI就当不存在。

## 三、怎么正确使用AI

### 用户层：告诉AI你是什么人

不要假设AI会自动理解，每次开始新话题时明确说：
- "我是创业者，不是打工者"
- "我要交付完整产品给客户，不是交付代码"
- "前端是必需品，不是可选项"
- "我的北极星是AI全栈工程师"

### 用户层：给AI足够的上下文

AI的判断质量取决于你给的信息量：
- 给模糊需求 → 得模糊判断
- 给完整背景 → 得精准判断
- 给错了背景 → AI会用错误背景判断

### 用户层：知道AI的判断哪里会失灵

AI容易失灵的领域：
- **不理解的领域**：SR.D/Motion Sites，AI没有设计审美，不会用设计展示网站
- **缺少训练的领域**：客户心理、商业决策
- **上下文没覆盖的领域**：每次换话题都是新的上下文窗口

### 用户层：交叉验证AI的判断

遇到AI说"这个没用/不收/不需要"，追问：
- "你是基于什么判断的？"
- "你有没有调用[某个领域的]知识？"
- "这个判断是推理出来的，还是因为上下文里没提到所以默认不存在？"

## 四、知识录入原则：让AI不遗漏

### MEMORY必包含的内容

| 类型 | 为什么要写 |
|---|---|
| **角色定位** | 创业者视角，不是打工者 |
| **产品交付标准** | 完整产品，不是代码 |
| **前端是必需品** | 审美是竞争力，不是可选项 |
| **北极星** | AI全栈工程师，直播电商是切入点 |
| **能力边界** | 三个伙伴各自的强项和弱项 |

### 每次扩展知识时的规则

新增知识点时，同步更新MEMORY：
- 收了一个前端工具 → MEMORY里加"前端是交付必需品"
- 发现AI判断失灵 → MEMORY里加"AI上下文限制，需要主动告知"
- 明确了创业方向 → MEMORY里加"创业者视角"

## 五、三工具使用原则

### QClaw（知识教练）
强项：知识管理、学习教练、架构设计、资产归档
弱项：容易受上下文限制，只在窗口里调用知识
用法：给完整背景，让QClaw做知识判断；QClaw判断错了要指出

### 小舟（技术搭子）
强项：技术架构把关，项目期代码审查
弱项：学习期只读，不进场
用法：项目期才进场，进场前要让他知道我们的北极星和交付标准

### Codex（写码执行）
强项：代码生成、快速实现
弱项：前端丑，需要有人验收审美
用法：给明确需求和审美参照物（SR.D/Motion Sites），不然生成的界面会很难看

## 六、创业视角 vs 打工者视角

| 维度 | 打工者 | 创业者 |
|---|---|---|
| 交付物 | 代码/功能 | 完整产品（包含前端） |
| 前端 | 有别人做 | 自己必须解决 |
| 审美 | 加分项 | 门槛 |
| 判断标准 | 功能跑通 | 客户愿意付费 |
| 成功标准 | 领导满意 | 用户买单 |

**MEMORY里必须写清楚：你是创业者视角。**
