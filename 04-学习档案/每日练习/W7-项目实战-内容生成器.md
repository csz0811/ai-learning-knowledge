## 核心设计（值得记住）

### 1. 配置驱动架构
```python
CONTENT_TYPES = {
    "1": {"name": "小红书文案", "prompt": "..."},
    "2": {"name": "短视频脚本", "prompt": "..."},
    # 加新类型？复制改数字就行
}
```
**为什么好**：产品变，代码不用变。

### 2. 路径用 `__file__` 定位
```python
BASE_DIR = os.path.dirname(os.path.abspath(__file__))
out_dir = os.path.join(BASE_DIR, "outputs")
```
**为什么好**：在哪运行都行，文件不丢。

### 3. 双输出设计
- `.json`：机器读，可对接其他程序
- `.md`：人读，直接复制去发
