## 二、知识整合（D1-D7 核心）

### D1｜RAG 概述与 Embedding 原理
- **RAG = Retrieval（检索）+ Augmentation（增强）+ Generation（生成）**
- Embedding：文本 → 高维向量（MiniLM 输出 384 维）；相似度用余弦 / L2 距离
- **关键纠正**：找"语义最相近的块"是**检索器**（Embedding + 向量库 top-k）的事，在 LLM 出场前就完成；LLM 只负责综合归纳 top-k 片段
- RAG 为什么更准确：把"凭记忆生成"变成"先查资料再答"，大幅减幻觉

### D2｜ChromaDB 基础
- 装 `chromadb==1.5.9`（含 onnxruntime，约 40 依赖）；首次下载 all-MiniLM-L6-v2（79M）缓存后秒开
- **三件套**：`collection.add(documents, ids, metadatas)` / `collection.query(query_texts, n_results)` / `get_or_create_collection`
- Demo："哪家公司做手机" → 苹果 0.53 / 特斯拉 1.25（距离越小越像）
- **踩坑**：add 是"整行插入"，documents / ids / metadatas **永远等长**，否则报 `Unequal lengths`

### D3｜PDF 加载
- **PyMuPDF 替代 pdfplumber**：pdfplumber 依赖 cryptography 编译缺 Rust 工具链失败
- `fitz.open(path)` → `page.get_text()` 提取纯文本
- ⚠️ `fitz` API 已 deprecated，将来用 `import pymupdf`（现在警告无碍）
- 中文 PDF 乱码：默认字体不支持中文 → D5 用 reportlab STSong-Light CID 字体重生成

### D4｜文本切块策略
- 三参数：`chunk_size`（块大小）/ `overlap`（重叠）/ `step = chunk_size - overlap`（步进）
- 135 字 / chunk=20 overlap=10 → 切 7 块；overlap=0 → 切 5 块（重叠让边界语义连续）
- **"人工智能"拦腰切断实验**：块边界切在词中间 → 语义破碎，召回变差
- 经验：中文长文 chunk 500-1000，每块 = 一个完整知识点

### D5｜RAG 完整 Pipeline
- 链路：`read_pdf → chunk_text → embedding → ChromaDB.PersistentClient → query`
- **D5 bug（我写错，非你手敲错）**：`DB_PATH` 没独立出来，PDF 路径误用在 `path=` 导致报错；修复后加 `DB_PATH` 独立变量 + `os.path.basename(PDF_PATH)` 取文件名做 metadata
- `PersistentClient(path=...)` 的 path 必须是**目录绝对路径**，不是 PDF 路径
- 中文测试 PDF `test_zh.pdf`（5 页直播带货）用 reportlab STSong-Light 生成，解决乱码
- chunk=200 → 430 字切 3 块；query="python" 距离 1.753

### D6｜语义搜索深化
- 完整链路：query → embedding → 与库内向量算距离 → 取 top-k
- **距离阈值**：ChromaDB 默认 L2，越小越相似，**真相关通常 < 1.0**；库里没答案时硬返"最靠近"的块
- **「召回最相似 ≠ 相关」**：向量只认语义不认事实 → **检索质量决定 RAG 天花板**
- metadata 过滤：`where={"来源": "xx.pdf"}`；**多条件必须用 `$and` 嵌套**（ChromaDB 0.4.24 不支持并列字段）
- 召回质量受 MiniLM 中文短文本限制（W11 换 BAAI/bge-small-zh）
- 检索质量评估 3 关：① 距离 < 1.0 ② top-1 是否就是要的块 ③ 不同问法是否召回同一块

### D7｜RAG 流程图（收官）
- 两大阶段：**离线建库**（文档→切块→向量化→存库）/ **在线检索**（问题→embedding→top-k→拼 Prompt）
- 离线阶段完全不碰 LLM；在线检索前半段也不碰 LLM，只有最后拼 Prompt 才进 LLM
- **W11 衔接**：[D5+D6 检索] → top_k 块 → 拼 Prompt → DeepSeek API → 结构化答案
- 代码载体 `w10_d7_rag_flowchart.py`（ASCII + Mermaid 双版本）

## 三、📝 复习清单

### 必背知识点（可默写）
1. RAG 三阶段：Retrieval / Augmentation / Generation
2. Embedding：文本→向量；相似度越小越像（L2）/ 越大越像（余弦）
3. ChromaDB 三件套：add(documents, ids, metadatas) / query(query_texts, n_results) / get_or_create_collection
4. 切块三参数：chunk_size / overlap / step = chunk_size - overlap
5. PersistentClient 的 path = **目录绝对路径**（不是 PDF 路径）
6. 距离阈值：真相关通常 < 1.0；「最相似 ≠ 相关」
7. where 多条件必须 `$and` 嵌套；中文字段名（如 `来源`）要和 add 时完全一致

### 常见错误（能说出 3 个）
1. **add 三件套不等长** → `Unequal lengths`（doc/id/metadata 永远等长）
2. **PersistentClient(path=PDF_PATH)** → 把 PDF 路径当目录路径，报错；应独立 `DB_PATH`
3. **where 并列字段** → `Expected where to have exactly one operator`；改用 `{"$and": [{...}, {...}]}`
4. （附加）**fitz 已废弃** → 将来 `import pymupdf`；现在警告可忽略

### 自测小测（5 题，口头答）
1. RAG 里"找语义最相近的块"是谁干的？—— 检索器（Embedding + 向量库），不是 LLM
2. ChromaDB `add` 的 documents / ids / metadatas 有什么关系？—— 必须等长，整行插入
3. `chunk_size=100, overlap=20`，step 是多少？切出的块之间重叠多少字符？—— step=80；重叠 20 字符
4. query 距离 1.2，库里有答案吗？—— 大概率没有（>1.0 通常是不相关，"最不烂"的块）
5. 想按"来源=xx.pdf 且 块编号≥2"过滤，where 怎么写？—— `{"$and": [{"来源":"xx.pdf"}, {"块编号":{"$gte":2}}]}`

### 核心代码片段
```python
# D5 建库（修好的版本）
import os, chromadb
PDF_PATH = "/Users/hechengfajituan/ai-assistant/test_zh.pdf"
DB_PATH  = "/Users/hechengfajituan/ai-assistant/chroma_db"   # 独立目录变量
PDF_NAME = os.path.basename(PDF_PATH)                        # 取文件名做 metadata
client = chromadb.PersistentClient(path=DB_PATH)
collection = client.get_or_create_collection(name="pdf_knowledge")
collection.add(documents=chunks, ids=ids,
               metadatas=[{"来源": PDF_NAME, "块编号": i} for i in range(len(chunks))])

# D6 检索 + 距离判断
def test_query(q, n_results=3):
    r = collection.query(query_texts=[q], n_results=n_results)
    for doc, dist in zip(r['documents'][0], r['distances'][0]):
        print(f"{'✅' if dist < 1.0 else '❌'} 距离={dist:.3f} {doc[:40]}")

# D6 metadata 多条件过滤（必须 $and 嵌套）
collection.query(query_texts=["复盘"], n_results=2,
                 where={"$and": [{"来源":"test_zh.pdf"},
                                 {"块编号": {"$gte": 2}}]})
```

### 脚本目录锁定（代码规范）
```python
import os
BASE_DIR = os.path.dirname(os.path.abspath(__file__))
DB_PATH = os.path.join(BASE_DIR, "chroma_db")
```
- ChromaDB PersistentClient 的 path 必须是目录绝对路径，不是 PDF 路径
- 变量命名不复用（D5 bug：PDF_PATH 误用为 DB_PATH 导致报错）

### reportlab 中文 PDF 方案
- 用内置 CID 字体 `pdfmetrics.registerFont(UnicodeCIDFont('STSong-Light'))`
- 无需额外字体文件，跨平台稳定（避免 macOS .ttc 索引问题）

### RAG 知识库构建原则（W10-D7 确认）
- 数据来源 = 客户公司内部真实资产（产品表/历史弹幕/话术SOP），不是网上搜的泛知识
- 内容取舍三原则：特有性>通用性 / 高频性>低频性 / 时效性须标版本日期
- 完美库 5 维度：多源聚合 / 粒度适中(1 chunk=1知识点) / 元数据丰富 / 更新机制 / 去重
- FAQ 机器人受众 = 客户团队（主播/客服），不是客户本人；客户付的是"隐性知识→可服务知识"的转换费
