### 核心概念深层理解

#### if/elif/else 互斥性（最重要概念）
```python
score = 85
if score >= 90:        # 只走一个分支，互斥！
    grade = "A"
elif score >= 75:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "D"
# score=85 走第二个分支 → grade="B"
# ❌ 如果写成三个 if（不是 elif），三个分支都会判断，grade 会被覆盖三次
```
**互斥 = 防止重复执行**，只执行第一个满足条件的分支

#### 切片：左闭右开（最容易错的语法）
```python
s = "hello"
s[0:3]   # "hel"，含索引0，不含索引3
s[1:4]   # "ell"，含索引1，不含索引4
s[:3]    # "hel"，省略0等于0
s[2:]    # "llo"，省略末尾等于到最后
s[-2:]   # "lo"，负数从右边数
```
**口诀：包含左边，不含右边**

#### 字典三件套
```python
d = {"苹果": 5, "香蕉": 3}
d.keys()    # dict_keys(['苹果', '香蕉'])
d.values()  # dict_values([5, 3])
d.items()   # dict_items([('苹果',5), ('香蕉',3)])，每个是元组

# 遍历字典
for key in d.keys():
    print(key, d[key])

for key, val in d.items():
    print(f"{key} 有 {val} 个")
```

#### while vs for（选择原则）
| 场景 | 用哪个 | 原因 |
|:---|:---|:---|
| 已知循环次数 | `for i in range(5)` | 更简洁 |
| 不知道次数（等用户输入） | `while True: if valid: break` | 灵活控制 |
| 遍历列表/字典 | `for item in list` | 天然迭代 |

- [ ] 能默写 `if` `elif` `else` 三个关键字

- [ ] 能写出「成绩评级」的条件判断代码（90+ / 75-89 / 60-74 / <60）

---

## 二、循环 while / for

- [ ] `while` 循环的特点：**先判断条件，再执行循环体**（条件不满足时可能一次都不执行）
- [ ] `while` 循环里必须有**改变条件的代码**，否则会死循环
- [ ] `for` 循环的特点：**遍历一个已知序列**（字符串/列表/范围）
- [ ] `while` 适合「不知道要循环多少次」；`for` 适合「已知循环次数」

---

## 三、数据结构：字符串切片 & 字典

- [ ] 切片语法 `s[起始:结束]`：**左闭右开**（含头不含尾）
  - 例：`"hello"[1:4]` = `"ell"`（不是 `"ell "`）
- [ ] 字典的三个核心操作：
  - `dict.keys()` → 所有键
  - `dict.values()` → 所有值
  - `dict.items()` → 所有键值对
- [ ] 字典的 key 必须是**不可变类型**（字符串/数字），不能用列表

---

## 四、循环中的 break 与 continue

- [ ] `break`：**立刻跳出整个循环**
- [ ] `continue`：**跳过本次循环剩余代码，继续下一次**
- [ ] 能区分两者的使用场景

---

## 五、转义字符

- [ ] `\n` = 换行
- [ ] `\t` = 制表符（Tab）
- [ ] 能写出「打印表格」例子（用 `\t` 对齐）

## 六、防御性编程（W2 核心扣分点）

- [ ] 循环里忘记 `break` 会导致**死循环**
- [ ] 条件判断不用 `elif` 而用多个 `if` 会导致**条件不互斥**
- [ ] `while` 条件写反了会**死循环**
- [ ] 能说出「互斥结构」为什么重要（防止重复执行）
