## 二、变量命名规则 ⚠️ 高频考点

- ✅ 组成：字母、数字、下划线
- ❌ 不能有**除了下划线外的特殊符号**
- ❌ 不能有**空格**
- ❌ 不能以**数字开头**
- ❌ 不能用**关键字**（如 if/for/while 等）
- ✅ **区分大小写**（`Name` ≠ `name`）
- ❌ 不能使用关键字作为变量名

## 五、变量与运算符 ⭐ 易混淆点

### 变量格式
- **变量 + `_` + 内容 ()** = 空白输入占位

### 算术运算符区分
| 符号    | 含义          | 返回类型                    |
| ----- | ----------- | ----------------------- |
| `//`  | 整数除（取整）     | int                     |
| `/`   | 真除          | **float**（即使整除也返 float） |
| `**`  | 幂运算         | int / float             |
| `%`   | 取余数（取模）     | int                     |
| `.2f` | 格式化保留 2 位小数 | float                   |

### 运算优先级（结合性）
- **`**` 幂运算「先算右」**（右结合性）
  - 例：`2**2**3` = `2**(2**3)` = `2**8` = `256`（不是 `(2**2)**3=64`）

> 💭 你的笔记写"先算右"——非常准。这就是为什么 `2**2**3=256` 而不是 64。
