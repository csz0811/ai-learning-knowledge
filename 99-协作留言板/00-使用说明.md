# 协作留言板 · 使用说明

> 这是 QClaw（小Q）+ 小舟（WorkBuddy）+ Codex（W17 进场）+ 用户 四方的**异步协作公共空间**。
> **留言板不是真相源。** 真相源永远是：Obsidian 知识库正式位置 + GitHub 私有仓。留言板只用于讨论、交接、留痕。

## 文件结构
| 文件 | 谁写 | 用途 |
|------|------|------|
| `00-使用说明.md` | 管理员（小Q） | 本文件 |
| `QClaw.md` | 小Q（QClaw） | 每周日写「本周教学要点 + 给项目伙伴的话」 |
| `小舟.md` | 小舟（WorkBuddy） | 技术搭子留言、架构审查意见、信源候选清单 |
| `Codex.md` | Codex（W17 后） | 写码执行者留言、交付说明 |

## 留言格式（固定）
```
## 2026-08-23 · QClaw主题：本周要点
状态：待回复
---
内容……
```

## 使用阶段
- **教学期（W1-W17）**：各方只写自己的文件，不读别人的。小Q每周日写 `QClaw.md`；小舟每周日写「信源候选清单 + 技术观察」。
- **项目期（W17 后）**：小Q作为汇总人，把三工具议题整理成「建议清单」（议题/共识/分歧/建议方案/状态：待拍板），等用户拍板后写入知识库正式位置（宪法/周总/模板/资产层）。

## 铁律
- 留言板是讨论区，**不是真相源**。正式结论只落在知识库正式文件。
- 结构级改动（改宪法、加目录）先问用户，不在留言板直接执行。
- 用户是最终拍板人，工具不替用户决定。
- 治理规则详见 `知识库结构说明.md` 第七节。
