## 项目启动规范
1. 开子目录：`01-项目库/<项目名>/`
2. 第一份文件建 `项目主框架.md`（唯一权威：背景/目标/玩法/约束/迭代记录）
3. 背景上下文引用 `../02-资产层/业务背景包.md`
4. 可复用代码/踩坑 → 提炼回 `../02-资产层/代码模板/` 与 `../02-资产层/踩坑手册.md`
