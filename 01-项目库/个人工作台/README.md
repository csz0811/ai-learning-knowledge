# 个人工作台（练手项目）

> ⚠️ **勿与「个人AI工作台」混淆**：本项目是**本地效率工具**（三抽屉工作台 V1.1 终态 + V2 转型「雷达项目集成宿主」）；`01-项目库/个人AI工作台/` 是另一个**规划中**的想法（AI Agent 工作台，攒痛点中，未启动）。

## 项目是什么

- **形态**：单 HTML 文件本地 Web 应用（双击 file:// 打开，无服务器、无依赖）
- **功能**：收件箱（无摩擦暂存）→ 任务板（做事，可打勾归档）→ 素材库（长期资产，标签+搜索）三抽屉，外加卡片详情弹层、删除、JSON 导出备份/导入恢复、Markdown 阅读版导出（V1.1 终态，约 1200 行）
- **定位**：练手项目——目标是跑通「想法 → 需求清单 → PRD → 变更管理 → 分工序开发 → 验收 → 复盘」完整闭环。**闭环已跑通 ✅**；V1.1 因两端断裂封存（#18），**当日复活转型 V2「雷达项目集成宿主」（#19）**
- **时间**：2026-08-27 半天需求 + 08-29 一天 V1.0 + 08-31 半天 V1.1 与封存，共约 2.5 个工作日；同日宣布复活进 V2
