## 项目是什么

- **形态**：单 HTML 文件本地 Web 应用（双击 file:// 打开，无服务器、无依赖）
- **功能**：收件箱（无摩擦暂存）→ 任务板（做事，可打勾归档）→ 素材库（长期资产，标签+搜索）三抽屉，外加 JSON 导出备份/导入恢复、删除
- **定位**：练手项目——目标是跑通「想法 → 需求清单 → PRD → 变更管理 → 分工序开发 → 验收 → 复盘」完整闭环，工作台本身是副产品
- **时间**：2026-08-27 半天需求 + 08-29 一天开发交付，共 2 个工作日

## 开发模式（脚手架）

小舟搭骨架（页面结构/CSS/数据框架/渲染/事件绑定），用户填核心逻辑（7 处：三个 add 函数、三行 concat、三行 filter）。核心逻辑全部用户亲手写过一遍。
