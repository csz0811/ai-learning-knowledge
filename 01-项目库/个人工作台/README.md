## 项目是什么

- **形态**：单 HTML 文件本地 Web 应用（双击 file:// 打开，无服务器、无依赖）
- **功能**：收件箱（无摩擦暂存）→ 任务板（做事，可打勾归档）→ 素材库（长期资产，标签+搜索）三抽屉，外加卡片详情弹层、删除、JSON 导出备份/导入恢复、Markdown 阅读版导出（V1.1 终态，约 1200 行）
- **定位**：练手项目——目标是跑通「想法 → 需求清单 → PRD → 变更管理 → 分工序开发 → 验收 → 复盘」完整闭环。**闭环已跑通 ✅，工具本体因两端断裂（入口在手机短视频场景/出口组稿未启动）封存**（变更记录 #18）
- **时间**：2026-08-27 半天需求 + 08-29 一天 V1.0 + 08-31 半天 V1.1 与封存，共约 2.5 个工作日
