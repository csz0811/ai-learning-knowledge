## 四、踩坑手册（真实坑，按出现顺序）

> 已提炼至 `02-资产层/踩坑手册.md`（统一管理），此处保留原文快照。

| # | 坑 | 表象 | 根因 | 修法 |
|---|---|---|---|---|
| 1 | 把 `input()` 写进 JS | 程序不对，不知道为什么 | 混淆「主动问用户」和「读已填的值」 | 读值用 `document.getElementById('id').value` |
| 2 | id 拼写错（nweContent） | 报错 null.value | id 必须一字不差 | 报错先查拼写，再查 id 是否真存在于 HTML |
| 3 | 孤儿括号 `}` | 报错指向 506 行但那里没错 | 报错行号 ≠ 犯错行号 | 数括号配对，从函数头往后配 |
| 4 | 整段照抄 if/else 套路 | 逻辑跑不通 | 抄前没问「它当时为什么存在」 | 抄前先问这段在原语境里干什么 |
| 5 | 变量遮蔽（外 let 内 const 同名） | 静默失败，外层变量永远 undefined | 同名变量在函数内重新声明，把外层盖住了 | 同一函数链里变量不重名 |
| 6 | 自造 id（newTitle2/newNote） | getElementById 拿到 null | 凭印象编 id，没回 HTML 核对 | 点名前先确认名字在 HTML 里真的存在 |
| 7 | 自造变量（tasks.inbox） | 运行时 ReferenceError，语法检查却通过 | 把「改数组名」做成改对象名 | 语法过 ≠ 跑得对；分清仓库（data）和抽屉（.inbox） |
| 8 | localStorage 环境隔离 | AI 助手预览面板里存的数据，浏览器打开就没了 | 预览是临时环境，和 file:// 是两套存储 | 日常一律双击 file:// 打开，预览只看界面 |

## 六、内化的句型（可直接带走下个项目）

> 已提炼至 `02-资产层/代码模板/localstorage_crud_vanillajs.md`（配方卡）。

- 读值：`document.getElementById('id').value`
- 空判断：`if (!x) return;`
- 三连招：`loadData() → data.xxx.push(item) → saveData(data)`
- 刷新+清空：`renderAll(); xxx.value = '';`
- 增（接数组）：`data.a = data.a.concat(imported.a)`
- 删（筛数组）：`data.a = data.a.filter(it => it.id !== id)`
- 前端纪律：**点名（id/变量）前先确认它存在**；**报错行号 ≠ 犯错行号**
