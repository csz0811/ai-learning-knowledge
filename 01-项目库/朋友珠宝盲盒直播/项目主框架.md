## 三、5 点大框架（用户 2026-08-24 给出）

### 1. 智能回复客服 〔楔子：弹幕FAQ · **降为后续（2026-08-26 朋友反馈客服场景少）**〕
- 范围：售前 / 售后 / 价格 / 物流（全包）
- 落地：客服场景（非弹幕、非微信）
- 技术：复用 W11 `rag_pipeline_langchain1x.md`（bge→Chroma→LCEL→DeepSeek）
- 口径：先手搓种子 Q&A，朋友补真实数据替换
- **🔴 数据采集闭环（隐性需求，2026-08-24 用户洞察）**：bot 触发「不知道」或低置信检索时，将问题+时间落 `unknown_questions.log`；定期人工补进 `faq_seed.md`，KB 自我滋养。理由：薄 KB 项目靠真实使用反哺才能脱离推导版；此需求源自「bot 上线即采集器」洞察，**非外部框架能教**，故显式写入避免遗漏（复用模式见方法论层）
- **🔴 查询预处理 / 输入归一化（隐性需求，2026-08-25 用户洞察）**：用户原始输入不可信（错别字 / 同义词混用 / 秒发不检查）。检索前加一层 **Query Rewriting（查询改写）**：把用户原始话先纠正错别字 + 同义词归一到规范问句（如"那怎么卖"→"怎么购买"）再检索。理由：①embedding 把"卖/买"当反义，错别字/同义直接进检索会漏 ②客服 bot 永远不能信原始输入。解法三选：LLM 改写（最省事，一次解决错别字+同义）/ 规则词典（快但需维护）/ hybrid。实现见 W12-D3 手敲版。

### 4. 爱复盘式 AI 复盘智能体（领域=珠宝盲盒直播，带提示词闭环）〔楔子：直播复盘 · **第一期（2026-08-26 提前）**〕
- **本质**：类似「爱复盘」的 AI 智能体（朋友现用爱复盘做同行拆解）；领域锁死在朋友珠宝盲盒直播，**不做泛型**
- **流程**：输入朋友直播内容/数据 → 拆结构化复盘（留存/互动/转化/**情绪节点(超量惊讶次数)**/玩法节奏）→ 给具体调整步骤
- **输入素材形态待确认（2026-08-26 新增）**：直播回放（→语音转写）/ 后台数据（→读图·录入）/ 人工描述（→纯文本）——技术路线分岔点，见项目工位待确认 #10
- **🔴 硬约束：提示词闭环**——复盘不是输出一次就完，要追踪「调整建议是否落地、下次是否改善」（朋友原痛点：Q&A 散慢 + 提示词无闭环）
- 对标：爱复盘式 agent（分析层）；飞瓜/蝉妈妈等仅作**数据来源参考**，非必选

### 5. 直播内容更好、单量更多（玩法优化）〔楔子：选品/玩法优化〕
- 关键：朋友直播内容**主要是玩法不是产品**
- 目标：优化玩法→提升情绪调动→提升单量
- 玩法机制见 第四节

## 四、珠宝盲盒玩法（详细机制）
- 品类：**珠宝**；玩法：**盲盒**
- 客单：**一单 99 元**
- 机制：发**颜色卡片**；有**相同颜色**卡片 → 加一条**手串**并回收该卡片；直到没有相同颜色 = 完成一单
- 随机性：一单 99 能获得手串**随机**，正常一单得 **8-9 条**手串
- **超量触发**：超过 8-9 条 = 运气好 → 此时主播**应有【惊讶情绪 + 台词】**
- 系统设计含义：玩法本身制造「惊喜/情绪波动」，正对应第二节「情绪调动」短板——**复盘系统可监测超量事件并触发主播台词提示**

## 五、违禁词（详见 `02-资产层/业务背景包.md` 第十节）
- 抖音官方两类：广告极限词 + 不规范变体表述 + 平台特有限流词
- 现成 skill：`douyin-sensitive-check`（ClawHub @yourlin，本地词库+每日更新，无需 API Key）
- 用法：第 2 点形容词生成 + 第 1 点 FAQ 回复**均须过滤**

### 7.2 推荐调整 / 新增技能 / 功能（初稿，待用户商谈拍板才执行）
- **点2 升级**：「形容词生成」→ 升级为「卖点话术 + 情绪钩子生成」（朋友本来不会描述产品，直接给能念的话术比形容词更实用）；并加「情绪/表情提示」功能（市面已有，对症朋友「软绵绵/无情绪」短板）
- **点5 差异化**：「超量→惊讶情绪+台词」做成**可配置的情绪触发规则引擎**（不只珠宝盲盒，未来其他玩法也能配规则）——这是市面工具没做到的细粒度，是我们的壁垒
- **点1 加兜底**：RAG 答不出时「转人工 / 留资」，不硬编（参考 Coze 结构）
- **点3 按域分检**：知识库按 售前/售后/价格/物流/玩法规则 分域，检索更准
- **点4 闭环硬约束**：复盘 agent 必须带「提示词闭环」（追踪调整落地+下次改善），不是一次性报告；维度=留存/互动率/转化/情绪节点(惊讶次数)/玩法节奏；数据可接抖音 API 或人工导入
- **横切必做**：①合规红线——AI 辅助、真人主导，不做纯自动直播（2026 平台严查录播，封号风险）②违禁词必过（已找到 `douyin-sensitive-check`）③新增技能组件：提词器上屏 / 情绪触发规则引擎 / 转人工兜底 / 复盘看板
