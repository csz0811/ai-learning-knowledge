## 一、项目是什么
- **本期交付**：朋友直播带货公司的「客服 FAQ 机器人」（5 点框架中的第 1 点）
- **大局**：用户给朋友画了 **5 点大框架**，FAQ 客服是第 1 楔子，其余 4 点是后续项目
- **归属**：直播电商六个楔子（弹幕FAQ / 话术生成 / 产品知识库 / 直播复盘 / 选品调研）的第一块

## 二、朋友公司情况
- 初创公司，**还没落地业务，处于探索阶段**
- 知识库内容很难从他那边汲取（无现成产品资料、业务未定型）
- 真实付费意愿强，但要的是「完整产品」不是「代码」

## 三、FAQ 覆盖范围（第 1 点）
- 售前 / 售后 / 价格 / 物流 —— 四类全包含
- 落地位置：**客服**（非弹幕、非微信）

## 四、关键约束
- **无现成产品资料** → W12 从零手搓种子 Q&A（覆盖四类），朋友后续补真实数据
- **知识难从朋友处汲取** → 我们主动建构，不依赖他提供文档

## 五、用户观察：朋友 vs 同行差距（用户实地对比得出）
- 主播直播中**没有情绪调动**，难留住人
- 说话**软绵绵**
- **产品描述基本没有**
- → 这是朋友当前最大短板，也是后续楔子（话术生成/复盘）要解决的

## 六、用户给朋友的 5 点大框架
1. **智能回复客服**（本期 W12）：自动答 FAQ
2. **产品图 → AI 生成形容词**（需排除抖音违禁词）→ 监控直播画面 → 监测到对应产品 → 形容词发到屏幕。待论证可行性
3. **RAG 知识库智能问答**：朋友以后招人不需要手把手教导，省时间（= 产品知识库楔子）
4. **监控直播复盘**：根据直播内容拆解，自动生成复盘数据 + 如何调整（具体步骤和做法）（= 直播复盘楔子）
5. **让直播内容更好、单量更多**：其直播内容主要不是产品而是**玩法**（= 选品/玩法优化）

## 七、真实业务：珠宝盲盒玩法（用户现场描述）
- 品类：**珠宝**；玩法：**盲盒**
- 一单 **99 元**
- 机制：发**颜色卡片**；有**相同颜色**的卡片 → 加一条**手串**并回收该卡片；直到没有出现相同颜色 = 完成一单
- 一单 99 能获得手串是**随机**的，正常一单得 **8-9 条**手串
- **超过 8-9 条 = 运气好** → 此时主播**应有惊讶的情绪 + 台词**
- 含义：玩法本身制造「惊喜/情绪波动」，这正对应第五点「情绪调动」短板

## 十、抖音违禁词调研（2026-08-24 查，用户提问）
- **是什么（抖音官方两类）**：
  1. 广告极限词：最/一/级极/首国家/绝对/迷信/医疗功效/虚假承诺（如「最佳」「第一」「顶级」「旺夫」「包治百病」）——见抖音电商规则中心《虚假宣传:使用广告极限词》
  2. 不规范变体表述：某商某场 / 维什么C / 抖抖平台 / 加微信→某信 等（平台不提倡但也不算敏感词，刻意规避反被疑）
  3. 平台特有限流词：私信 / 加微信 等诱导互动词
- **怎么获得**：①抖音电商学习中心规则中心（官方最权威）②开源词库：konsheng/Sensitive-lexicon（14万条）、wordscheck（76万词组）、houbb/sensitive-word ③在线工具：零克查词 / 句易网 / 句无忧
- **✅ 现成 skill 可套用/拆解**：`douyin-sensitive-check`（ClawHub @yourlin）——本地词库+每日自动更新，无需 API Key，离线可用。安装：`openclaw skills install douyin-sensitive-check`。另 chinese-sensitive-words-mcp（MCP，支持抖音，风险分级+替换建议）
- **本项目用法**：第 2 点「形容词生成」必须接违禁词过滤；FAQ 机器人生成的回复也应过滤
