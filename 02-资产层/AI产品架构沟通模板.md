# AI产品架构沟通模板

> 用七层模型想清楚之后，怎么把这些告诉 AI？
> 按这个格式描述，AI 给的方案质量更高。

---

## 通用句式

**开头一句话：**
> "我要做一个 [系统名称]，帮我设计架构。"

**结尾一句话：**
> "请基于以上信息，完成这个系统的设计和实现，包括：技术选型、完整代码、测试用例、部署方式。"

---

## 每层怎么描述给 AI

---

### 第一层：UI设计层

**模板：**
> "用户通过 [入口] 使用这个系统。"
> "界面主要包含 [核心页面/功能区]。"
> "用户操作流程是：[步骤1] → [步骤2] → [步骤3]。"

**举例：**
> "用户通过内部网页使用这个系统。界面只有一个搜索框。操作流程是：输入问题 → 等待3秒 → 看到回答和来源文档。"

---

### 第二层：核心价值层

**模板：**
> "目标用户是 [人群]，他们的问题是 [描述问题]。"
> "这个系统能让他们 [具体改变/节省多少]。"

**举例：**
> "目标用户是直播运营团队，他们的问题是每次要翻很多文档找答案。系统能让他们5秒出答案，不用再翻文档。"

---

### 第三层：skill层

**模板：**
> "系统需要这些能力：[能力列表]。"
> "不需要这些：[明确排除的能力]。"

**举例：**
> "系统需要：1) RAG 检索 2) LLM 生成回答。不需要：工具调用、长期记忆、多 Agent 协作。"

---

### 第四层：运行逻辑层

**模板：**
> "核心流程是：[步骤1] → [步骤2] → [步骤3]。"

**举例：**
> "核心流程是：用户提问 → 问题向量化 → ChromaDB 检索 → 拼 Prompt → DeepSeek 生成 → 返回回答。"

---

### 第五层：数据层

**模板：**
> "输入数据来自 [来源]，存储在 [存储方案]。"

**举例：**
> "输入数据是管理员上传的 PDF，存储在本地文件系统。向量存在 ChromaDB，配置存在 JSON 文件。"

---

### 第六层：接口层

**模板：**
> "对外提供 [协议] 接口。"
> "核心接口是 [接口名]，输入 [格式]，输出 [格式]。"

**举例：**
> "对外提供 FastAPI HTTP 接口。核心接口是 POST /ask，输入 JSON {question}，输出 JSON {answer, sources}。"

---

### 第七层：安全与部署层

**模板：**
> "部署在 [平台]。"
> "鉴权方式是 [方式]。"

**举例：**
> "部署在 Zeabur。鉴权方式是 API Key，每个部门一个 Key，可撤销。"

---

## 完整示例（把你的知识库系统发出去）

```
我要做一个企业内部知识库问答系统，帮我设计架构。

【用户界面】
用户通过内部网页使用，界面只有一个搜索框。
操作流程是：输入问题 → 等待3秒 → 看到回答和来源文档。

【核心价值】
目标用户是内部员工，他们的问题是查找分散在各种文档里的信息要花很多时间。
这个系统能让他们5秒找到答案。

【所需能力】
系统需要：RAG 检索、LLM 生成回答。
不需要：工具调用、多 Agent 协作。

【运行逻辑】
核心流程是：用户提问 → 问题向量化 → ChromaDB 检索 → 拼 Prompt → DeepSeek 生成 → 返回回答。

【数据】
输入数据是管理员上传的 PDF，存储在本地文件系统。
向量存在 ChromaDB，配置存在 JSON 文件。

【接口】
对外提供 FastAPI HTTP 接口。
核心接口是 POST /ask，输入 JSON {question}，输出 JSON {answer, sources}。

【安全与部署】
部署在 Zeabur。
鉴权方式是 API Key，每个部门一个 Key，可撤销。

请基于以上信息，给我：
1. 技术选型建议和理由
2. 完整代码（可直接运行）
3. 测试用例
4. 部署方式
```
