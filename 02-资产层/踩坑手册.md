## 项目：个人工作台（练手，V1.0，2026-08-29）

> 原始记录：`01-项目库/个人工作台/复盘_V1.0.md` 第四节。纯原生 JS + localStorage 单页应用。

### 1. 把 `input()` 写进 JS
- 【场景】网页表单读用户输入，从 Python 习惯迁移
- 【坑】在 JS 里写 `input('请输入内容')`，程序不对且不知道为什么
- 【修】JS 网页模式是「用户先填、代码后读」：`document.getElementById('id').value`。主动询问是 Python 脚本的交互模式，网页里不存在

### 2. id 拼写错（nweContent）
- 【场景】getElementById 读输入框值
- 【坑】id 拼错（newContent 写成 nweContent），报错 `Cannot read properties of null`
- 【修】报 null.value 类错误，先查拼写、再回 HTML 确认 id 一字不差地存在

### 3. 孤儿括号 `}`
- 【场景】手敲代码后删改，误删/多删一个花括号
- 【坑】报错指向第 506 行，但 506 行看起来完全没错
- 【修】报错行号 ≠ 犯错行号——括号不配对时 JS 要解析到很后面才炸。从函数头开始逐对数括号

### 4. 整段照抄 if/else 套路
- 【场景】新函数和旧函数长得像，把旧函数整段复制过来改
- 【坑】抄来了原语境里的空值判断/else 分支，新场景根本不需要，逻辑跑不通
- 【修】抄任何套路前先问一句：这段在原来的地方是干什么用的、我这里有没有它的存在条件

### 5. 变量遮蔽（外层 let、函数内 const 同名）
- 【场景】外层声明了 `let title`，函数内又写了 `const title = ...`
- 【坑】静默失败，不报错，但外层变量永远是 undefined——函数内的同名声明把外层盖住了
- 【修】同一函数链里变量不重名。比拼写错更危险：语法全过、运行不炸、结果就是不对

### 6. 自造 id（newTitle2/newNote）
- 【场景】写代码时凭印象引用页面元素
- 【坑】HTML 里根本没有 newTitle2/newNote 这两个 id，getElementById 拿到 null
- 【修】点名前先确认名字真的存在——回 HTML 核对，别靠记忆

### 7. 自造变量（tasks.inbox）
- 【场景】按「改数组名」的指令改代码，却改了点前面的对象名
- 【坑】写出 `tasks.inbox = ...`，但 `tasks` 变量根本不存在 → 运行时 ReferenceError，而语法检查是**通过**的
- 【修】语法过 ≠ 跑得对，运行时错误只有跑起来才现形。脑模型分两层：仓库（data，恒定）和抽屉（.inbox/.tasks/.materials，要换的是它）

### 8. localStorage 环境隔离
- 【场景】在 AI 助手的内置预览面板里测试存数据，之后双击浏览器打开工作台
- 【坑】预览里存的数据在浏览器里消失了
- 【修】预览是临时环境，与 file:// 打开的页面是两套 localStorage。日常使用一律双击 index.html（file://）打开，预览只看界面

## 项目：抖音广告财务后台（FastAPI + SQLite + JWT 前后端分离，2026-10-17 上线）

> 原始记录：`01-项目库/抖音广告财务后台/项目主框架.md`。第一个完整跑通并部署上线的项目。

### 1. SQLite 相对路径建错位置
- 【场景】`database.py` 写 `DB_PATH = "finance.db"`，用 `uvicorn --app-dir backend` 启动
- 【坑】数据库建到了启动时的 cwd（`E:\workbuddy_data\finance.db`），不在 backend 下；删库删错位置、旧账号一度「删不掉」
- 【修】`DB_PATH = os.path.join(os.path.dirname(os.path.abspath(__file__)), "finance.db")` 固定到脚本所在目录

### 2. 浏览器缓存旧页面
- 【场景】删掉登录页「默认管理员 admin/admin123」提示后，用户刷新仍看到旧提示
- 【坑】浏览器缓存了旧 HTML，用户以为没改，用 admin123 登录报「账号或密码错误」
- 【修】main.py 加 no-cache 中间件，对 HTML/JS 设 `Cache-Control: no-cache, no-store, must-revalidate`

### 3. prompt() 弹窗被禁用
- 【场景】用户管理「改密」用 `prompt()` 弹窗
- 【坑】在 WorkBuddy 预览面板里 prompt() 被禁用，点击毫无反应
- 【修】换成自定义 `<div class="modal">` 弹窗

### 4. PowerShell 引号被吃（curl 传 JSON）
- 【场景】用 curl 测接口，命令里写 `-d '{"username":"admin","password":"..."}'`
- 【坑】PowerShell 把内层引号吃了，后端收到空 body，登录失败
- 【修】JSON 写临时文件，curl 用 `--data-binary "@file.json"`

### 5. nohup 随 SSH 断开退出
- 【场景】远程服务器用 `nohup uvicorn ... &` 启动
- 【坑】SSH 断开后进程退出（没完全脱离终端）
- 【修】`nohup ... </dev/null >log 2>&1 &` 完全 detach；生产环境更正规用 **systemd 服务**（`Restart=always` + `enable` 开机自启）

### 6. 腾讯云防火墙默认只放行 22
- 【场景】服务在服务器本地 curl 200，但外网访问不了
- 【坑】腾讯云安全组默认只放行 22（SSH），8000 端口被拦，与「国内/国外网络」无关
- 【修】控制台 → 防火墙 → 添加规则 → TCP 8000 允许

### 7. iOS 数字键盘无小数点
- 【场景】手机端金额输入框用 `type="number"`
- 【坑】iOS 竖屏数字键盘没有小数点，记「1.22」难输入；且输入框字号 <16px 时 iOS 聚焦会自动放大整页
- 【修】金额框加 `inputmode="decimal"`；输入框字号提到 16px

### 8. FastAPI 可选参数用 Query(None) 直调报错
- 【场景】summary 接口加 `start_date`/`end_date` 可选查询参数，用 `Query(None)`
- 【坑】真实 HTTP 请求正常，但直接调用函数测试时把 Query 对象当默认值传入，报 `type 'Query' is not supported`
- 【修】用 `str = None` 代替 `Query(None)`（FastAPI 仍识别为可选查询参数，且直调安全）
