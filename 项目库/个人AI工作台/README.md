# 个人AI工作台

> 记录个人 AI 工作台的搭建规划。

## 一、它是什么

**个人 AI 工作台 = 你所有 AI 能力的控制中心。**

把跟你有关的 AI 工具串起来，让你一个地方控制所有。不是大杂烩，是真正的"AI 操作系统"。

## 四、核心功能清单

**来自思之的真实需求（2026-08-19）：**

- [ ] 聊天式界面，能记住我是谁
- [ ] 换窗口不觉得是陌生人（记忆跨对话）
- [ ] 能一起写代码、做项目
- [ ] 能追踪学习进度
- [ ] 能提醒需要补充的事情
- [ ] 像合伙人一样，有判断、有建议
- [ ] 能集成多个 AI 工具（DeepSeek / Claude / GPT 等）
