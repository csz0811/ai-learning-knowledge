# 个人AI工作台

> 记录个人 AI 工作台的搭建规划。
> 当前状态：规划阶段，W17 之后启动。

---

## 一、它是什么

**个人 AI 工作台 = 你所有 AI 能力的控制中心。**

把跟你有关的 AI 工具串起来，让你一个地方控制所有。不是大杂烩，是真正的"AI 操作系统"。

---

## 二、为什么现在不急着搭

| 原因     | 说明                              |
| ------ | ------------------------------- |
| 工具还没学完 | W11-W17 还没学，搭出来的也是半成品           |
| 需求是想象的 | 现在没有真实项目，列的需求是"没有项目时想要的"，落地会偏差 |
| 浪费精力   | 搭完发现不好用，推倒重来，时间白花               |
| 有现成方案  | OpenClaw 就是最好的个人 AI 工作台原型，可以先用好 |

**结论：不设 W17 硬节点——工作台应从真实项目里长出来，不是凭空规划。**

W17 后立即有直播电商项目 + Codex 进场，先搭台会推迟交付。正确做法：从 W12 FAQ 机器人起，每次遇到"要是有个 XX 就好了"就记进 `OpenClaw局限日志.md`（日期 + 场景 + 想要什么）；攒够 3 条真实痛点再启动最小版。届时需求清单才有真实数据，而非想象的需求。

## 四、核心功能清单（决策版：OpenClaw 已覆盖 vs 需自搭）

**来自思之的真实需求（2026-08-19），对照第五节 OpenClaw 现状：**

| 需求 | OpenClaw 现状 | 决策 |
|------|-------------|------|
| 聊天式界面，能记住我是谁 | ✅ 已覆盖（WebChat + SOUL/USER/MEMORY） | 不搭 |
| 换窗口不觉得是陌生人（记忆跨对话） | ✅ 已覆盖（MEMORY.md 跨会话） | 不搭 |
| 能一起写代码、做项目 | ✅ 已覆盖（代码生成/审查/执行） | 不搭 |
| 能追踪学习进度 | ✅ 已覆盖（MEMORY.md + 知识库） | 不搭 |
| 能提醒需要补充的事情 | ✅ 已覆盖（Cron） | 不搭 |
| 像合伙人一样，有判断、有建议 | ✅ 已覆盖（SOUL.md 角色设定） | 不搭 |
| 能集成多个 AI 工具（DeepSeek/Claude/GPT） | ✅ 已覆盖（多模型路由） | 不搭 |

**结论**：现下 7/7 需求 OpenClaw 已覆盖，照单自建 = 做 OpenClaw 的劣化复刻。真实差异区只会在**真实项目**里出现（见 `OpenClaw局限日志.md`），届时再决定搭什么、不搭什么。
