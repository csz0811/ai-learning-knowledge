# UI 美感自检清单

> 每次做完界面，对着这 5 条检查。
> 知道自己为什么改，改的对不对。

---

## 检查顺序：先大后小

### 第一步：间距（Spacing）

**看什么：** 元素之间的距离是不是规律的

**常见问题：**
- 卡片之间时远时近
- 按钮和文字挤在一起
- 标题和下面的内容距离太大

**怎么检查：** 打开界面，数一数相邻元素之间的"空白"是不是差不多大

**发现问题怎么说：**
```
"这几块之间的间距不一致，第一块16px，第二块8px，需要统一成16px"
"标题和内容的距离太近了，至少留12px"
```

---

### 第二步：对齐（Alignment）

**看什么：** 同类元素的边缘或中心是不是在一条线上

**常见问题：**
- 文字左对齐，但图标没对齐
- 按钮的位置忽左忽右
- 列表项的图标不在同一列

**发现问题怎么说：**
```
"这三个按钮应该左对齐，现在第一个靠左，第二个居中，第三个靠右"
"这段文字应该和左边的卡片边缘对齐"
```

---

### 第三步：对比（Contrast）

**看什么：** 重要元素和背景之间够不够明显

**常见问题：**
- 按钮颜色和背景太接近，看不清
- 次要文字颜色太浅，读起来费劲
- 选中状态和默认状态差别太小

**检查方法：** 把界面截图标灰（黑白模式），看不清的地方就是对比度不够

**发现问题怎么说：**
```
"按钮颜色#666666和背景#555555对比度不够，改成#ffffff"
"次要说明文字太灰了，正常视力看着费劲，改成#666666"
```

---

### 第四步：层级（Hierarchy）

**看什么：** 一眼看过去，先看到什么，其次看到什么

**常见问题：**
- 标题和正文一样大，看不出哪个是标题
- 所有内容都一样重要，没有主次
- 按钮和普通文字用了一样的视觉权重

**检查方法：** 眯着眼睛看界面，最醒目的应该是最重要的内容

**发现问题怎么说：**
```
"标题字号太小（14px），应该比正文（16px）更大，改成20px"
"这个重要的按钮应该比普通文字更突出，加上背景色"
"次要信息（时间/来源）应该用更小的字号和更淡的颜色"
```

---

### 第五步：留白（White Space）

**看什么：** 是不是塞得太满，喘不过气

**常见问题：**
- 所有地方都填满了，没有呼吸空间
- 卡片内容太多，挤在一起
- 页面没有边距，内容顶到边缘

**发现问题怎么说：**
```
"页面左右留白太少，加上至少16px的padding"
"这个卡片内部太挤了，padding从8px改成16px"
"标题下面留白不够，至少留8px"
```

---

## 快速口诀

> **"间距对整齐，对比要清晰，层级分主次，留白呼吸感"**

---

## 发现问题后的改法优先级

| 优先级 | 动作 | 举例 |
|--------|------|------|
| 1 | 调间距 | 统一 padding/margin |
| 2 | 调字号 | 标题/正文/说明 三个层级 |
| 3 | 调颜色 | 主色/次要色/禁止色 |
| 4 | 调对齐 | 统一左对齐/居中 |
| 5 | 加圆角/阴影 | 适度，不要过度 |

---

## 给 AI 提需求的万能句式

```
"检查并修正以下问题：
1. 所有卡片内 padding 统一成 16px，卡片间距 24px
2. 所有文字左对齐
3. 标题颜色改成 #1a1a1a，正文改成 #333333，说明文字改成 #666666
4. 标题 20px，正文 16px，说明文字 14px
5. 按钮圆角 8px，卡片圆角 12px"
```
