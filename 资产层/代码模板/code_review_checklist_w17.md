## 审查清单（给 AI 的具体指令模板）

让 Codex（或其他 AI 编程工具）检查代码时，**别只问"有没有问题"**，改用以下具体检查项：

```
请重点检查以下方面：
1. 空值处理（None/null 是否判断）
2. 重复请求（接口是否去重）
3. 并发安全（多线程/多进程风险）
4. 权限控制（访问控制是否完整）
5. 超时处理（API/数据库超时是否设置）
6. 异常处理（try/except 是否覆盖关键路径）
7. 敏感信息泄露（API key/密码是否硬编码）

问题问得越具体，检查结果越有价值。
```

## 对应用户短板

| 检查项 | 用户历史短板 | 相关踩坑 |
|---|---|---|

| 并发安全 | 未系统学习 | W12-W17 项目期可能遇到 |
| 权限控制 | 未系统学习 | API key 管理、部署安全 |
| 超时处理 | 未系统学习 | API 调用阻塞风险 |
| 异常处理 | 防御性编程弱 | W2-W4 多次踩坑（except 只捕 try 内异常等） |
| 敏感信息泄露 | 已注意 | `.env` + gitignore 正确实践 |
