> 本分支存"怎么想、怎么干"的元知识：产品思维、产品架构、可落地、怎么和 AI 协作、学习方法论等。
> 与 项目层(真实交付) / 资产层(拿来用的代码与业务) / 学习档案(结业历史) 并列，是第三类。
> 维护权：小舟（2026-08-25 起）。

## 收录什么
- 产品思维 / 产品架构 / 可落地方法论
- 与 AI 协作的工作流、沟通范式
- 从其他地方汲取、经辨析确认后值得长期保留的思维框架
- 个人做事原则、决策框架

## 新增知识的治理规则（重要 · 详见 `知识库结构说明.md` 第五节）
用户从其他地方（短视频/文章/其他 AI/书）带来新知识时：
1. 先就内容讨论、辨析（用 5 条标准评估，不盲从）。
2. **用户决定是否添加**——不静默写入。
3. 用户确认后，由助手归类：能归入现有四层 → 存入对应分支；是全新类别 → 助手提议新建库/分支，用户确认后建。
4. 存入时蒸馏成可复用卡片，不堆原文。
